# Nilasa Luxury Storefront & Admin Portal

Production-ready Next.js 14 luxury ethnic wear storefront and enterprise admin control portal for Nilasa.

---

## 🌸 Features

- **Storefront**: Handcrafted Indian ethnic womenswear, suits, kurtis, co-ords, and zari dupattas.
- **Color Palette**: Olive Green (`#354232`), Soft Lavender (`#8E6EA8`), and Pure White (`#FFFFFF`).
- **Responsive Mobile Navigation**: Dedicated 5-item bottom bar, single responsive search bar, and interactive drawer filters.
- **Admin Control Portal (`/admin`)**: Catalog management, order fulfillment, coupon engine, and user access control.
- **Clean Architecture & CQRS Backend Integration**: Direct connection with Nilasa .NET backend API.

---

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) for storefront and [http://localhost:3000/admin](http://localhost:3000/admin) for admin portal.
